# Jewelry Admin UI

Trabaja sobre un proyecto Laravel.

## Stack

- Laravel
- Blade
- Tailwind CSS
- JavaScript solo cuando sea necesario
- No React
- No Vue
- No Bootstrap

## Objetivo

Crear un panel administrativo moderno, elegante, limpio y premium para un e-commerce de joyería.

## Estado actual

Actualmente solo se está desarrollando la parte visual.

No conectar todavía con base de datos.

No crear:

- migraciones
- modelos
- seeders
- consultas SQL
- APIs
- autenticación

salvo que el usuario lo solicite explícitamente.

## Diseño

La interfaz debe sentirse:

- elegante
- moderna
- premium
- limpia
- profesional
- fácil de usar

Usar:

- fondos claros
- cards blancas
- navegación oscura o neutra
- dorado suave como color de acento
- bordes discretos
- sombras suaves
- buen espaciado

Evitar abusar del color dorado.

## Layout administrativo

Crear un layout reutilizable con:

### Sidebar

- Dashboard

Catálogo

- Productos
- Categorías
- Colecciones
- Materiales
- Piedras
- Tallas
- Variantes

Ventas

- Pedidos

Inventario

- Existencias
- Movimientos

Marketing

- Banners
- Newsletter

Configuración

- Datos de la tienda
- Pagos
- Envíos
- Usuarios administrativos

### Topbar

Debe incluir:

- título de la página
- breadcrumbs
- botón para abrir/cerrar sidebar
- notificaciones visuales
- avatar de administrador
- menú de usuario

## Dashboard inicial

Usar solamente datos ficticios.

Mostrar cards de:

- Ventas del mes
- Pedidos
- Productos
- Stock bajo

También incluir:

- gráfica visual de ventas
- pedidos recientes
- productos con stock bajo
- productos más vendidos

## Reglas de implementación

- Usar Blade.
- Usar Tailwind CSS.
- Crear componentes reutilizables cuando convenga.
- Diseño responsive.
- Sidebar adaptable a móvil.
- Mantener el código organizado.
- No instalar paquetes innecesarios.
- No agregar funcionalidades no solicitadas.
- No conectar datos reales todavía.
